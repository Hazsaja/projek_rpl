# AI RULES

Dokumen ini berisi aturan yang harus dipatuhi oleh AI Coding Assistant.

Contoh:

- GitHub Copilot
- OpenAI Codex
- Cursor AI
- Windsurf
- Claude Code

---

# Tujuan Sistem

Sistem Pelayanan Administrasi Desa.

Masyarakat dapat mengajukan surat secara online tanpa harus datang ke kantor desa.

---

# Prioritas Sistem

1. Stabilitas
2. Kemudahan Penggunaan
3. Aksesibilitas Lansia
4. Keamanan
5. Fitur Baru

---

# Aturan Pengembangan

AI HARUS:

- Memahami kode sebelum mengubahnya.
- Menjaga fitur lama tetap berfungsi.
- Menjaga kompatibilitas database.
- Menulis kode yang mudah dibaca.
- Menjaga konsistensi desain.

---

# Larangan

AI TIDAK BOLEH:

- Menghapus fitur yang sudah bekerja.
- Mengubah struktur database tanpa alasan.
- Mengubah alur bisnis.
- Mengubah warna utama aplikasi.
- Mengubah tata letak secara drastis.

---

# Aturan UI

UI harus:

- Sederhana
- Profesional
- Ramah lansia
- Mobile-first
- Responsive

---

# Aturan CSS

Gunakan:

- Flexbox
- CSS Grid

Hindari:

- Inline CSS
- Hardcoded Width berlebihan

---

# Aturan PHP

Gunakan:

- Prepared Statement
- Password Hashing
- Session Authentication

Hindari:

- Query SQL langsung dari input pengguna.
- Kode duplikat.
