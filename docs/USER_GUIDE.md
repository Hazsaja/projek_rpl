# USER GUIDE

# Panduan Masyarakat

## Login

1. Masukkan email/NIK.
2. Masukkan password.
3. Klik Login.

---

## Mengajukan Surat

1. Pilih menu Ajukan Surat.
2. Pilih jenis surat.
3. Isi formulir.
4. Upload dokumen persyaratan.
5. Klik Submit.

---

## Melihat Status

Masuk ke menu:

Riwayat Pengajuan

Status yang mungkin muncul:

- Menunggu Verifikasi
- Disetujui
- Ditolak

---

## Cetak Surat

Jika status:

Disetujui

maka tombol Cetak Surat akan tersedia.

---

# Panduan Admin

## Login

Masukkan akun admin.

---

## Verifikasi Pengajuan

1. Buka Pengajuan Masuk.
2. Periksa dokumen.
3. Pilih:

- Setujui
- Tolak

4. Simpan keputusan.

---

## Kelola Pengguna

Admin dapat:

- Menambah pengguna
- Mengubah data pengguna
- Menonaktifkan akun
